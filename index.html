Star Wars: Republic Commando — modding toolchain EXPERIMENT 1 CLOSED · 2026-09-14

What this is

A programmatic modding layer for a twenty-one-year-old Unreal Engine 2 game. Fourth in the forge family after ER Forge (Elden Ring), KOTOR Forge and AC6 Forge: an MCP server that reads and writes game state directly, so changes happen in a sentence instead of an afternoon in a 2005 editor.

Day one was deliberately spent measuring rather than building. Four assumptions that would have shaped the whole architecture turned out to be wrong — two in our favour, one against us, and one of them our own.

Done

  • Install located, fingerprinted (exe SHA-256 + launcher version), variant recorded as Steam.
  • Full vanilla snapshot of System\ and Save\ — 212 files — plus an 802-file MD5 manifest of all of GameData.
  • Toolchain pulled: SWRC Fix 2.15 & 2.13, the CT source tree, FirstPersonPlayer, UELib, UE Explorer 1.6.2.
  • SWRC Fix 2.15 installed; original System.ini preserved; language untouched.
  • UCC.exe smoke-tested; full commandlet surface captured.
  • Every asset container's header dumped and versioned by hand.
  • Asset export proven end to end — a real texture pulled out of a stock package to BMP, game files verified byte-identical afterwards.
  • The ucc pkg write path tested and disproven, then corrected everywhere it had been written down. See Architecture.

Not yet

  • No rc-forge code exists. The design is written; not a line of Python is shipped.
  • umodel / UE Viewer — the direct download 404s and the page is JS-gated. Needs a browser pass.
  • packages.md5 export table not yet decoded — we know its shape, not its contents.
  • Asset writing has no verified path. The commandlet everyone assumes exists doesn't. The replacement hypothesis is written up but untested.

Nothing on this page is a plan dressed up as progress. If it says done, it ran on the machine.

Four corrections to the received wisdom

MeasuredThe fourth correction is to us. This page originally claimed ucc pkg import texture gave us a safe asset write path. It was read off UCC's own printed usage text, and that text is a stub describing a command the binary does not implement. Testing it killed it the same day it was written. It is corrected in place rather than quietly deleted, because a project that only publishes its wins is not documentation, it is marketing.
Measured.ctm is not proprietary. File-type reference sites call Republic Commando's map format a closed binary requiring special software. It carries the plain Unreal package magic 0x9E2A83C1, version 159, licensee 1 — an ordinary UE2 map package with the extension renamed. No special casing, no reverse engineering.
MeasuredThe Karma physics files are XML. .ka and .kaw open with <?xml version="1.0"?>. The research budget allocated to reversing them went to zero.
MeasuredThe game did ship an editor. The community line is that Republic Commando shipped without one. unrealed.exe sits in GameData\System on the retail Steam build. What it shipped without was ucc.exe, the compiler — which the community rebuilt from scratch.

packages.md5 — the integrity check that isn't one

MeasuredIt is itself a 2,144-byte Unreal package exporting a PackageCheckInfo class with seventeen numbered instances, each carrying a pair of MD5 strings — one uppercase, one lowercase.

DocumentedThe mechanism is a multiplayer client-connect check over script packages only. It does not gate single player and it does not cover textures, sounds or meshes. The SWRC Fix author states the practical consequence outright: because no original game packages are modified, multiplayer keeps working.

The rule that falls out of this: never rewrite a stock .u, and the integrity manifest is simply never a topic. Every write surface below respects that.

OpenWhich seventeen packages does it actually cover? Decoding its export table is an early task, not a blocker.

The three that matter

pkg

ucc pkg list|expand <package>

list dumps a package's full summary, export and import tables — a free known-good reference to grade our own parser against. expand splits one into sub-packages, and writes into the game directory uninvited.

make

ucc make [-All] [-Silent]

Compiles UnrealScript from Code\<Package>\Classes\*.uc. Real script modding through the game's own compiler.

batchexport

ucc batchexport pkg.ext class ext path

Bulk extraction by class. Paired with exportbumpmaps for normal maps as TGA.

PropertyOverrides — the discovery that changed the design

SWRC Fix 2.12 added a mechanism that is barely mentioned anywhere outside a changelog line, and it is the single most important thing found today. Drop a text file at:

GameData\System\PropertyOverrides\<Package>.<Class>.txt

containing UnrealScript defaultproperties-style assignments, and the game applies them at startup. The shipped example, in full:

# Properties.BattleDroidBlasterTM.txt
AttachmentClass=Class'Properties.BattleDroidBlasterAttachmentTM'

Arbitrary class defaults, as plain text, with zero package modification. Weapon damage, squad health, AI behaviour, physics constants — all reachable without touching a single byte of a shipped file. Integrity manifest untouched. Multiplayer unaffected. Reversible by deleting a file. One file per class, which also makes mod conflicts detectable for free.

Configuration layering

Getting this backwards is the classic Unreal time-sink, so it is worth stating flatly:

  • GameData\System\*.ini — defaults. Read-only by policy. This is where you learn what the stock value is.
  • GameData\Save\System.ini and Save\Profile_<name>\User.ini — the live overrides. The game generates these with most values commented out, and values here win. Edit the first one and see no effect, and this is why.

Console handles worth knowing: set SWRCFix FOV, SetFpsLimit, userendev mod|d3d|opengl, flushresources, EditActor.

The governing principle

Always prefer the write surface that cannot corrupt anything. Republic Commando hands us three of them before a binary package writer is ever needed — so v1 ships without one.

SAFEST
ini overrides
Text. Save\System.ini and per-profile User.ini. Reversible by deleting a line.
SAFE
PropertyOverrides
Text. One file per class. Full gameplay-tuning surface with no package touched.
MEDIATED · HALF GONE
UCC
Reading out works (batchexport, pkg list). Writing assets back has no verified path — ucc pkg import turned out not to exist. ucc make for script is untested.
LAST RESORT · v2+
Binary writer
Raw UE2 read-modify-write. Gated behind a byte-exact round-trip harness. Only if the tier above proves insufficient.
MeasuredRung three is smaller than advertised. The experiment that was going to settle this asked whether ucc pkg import texture round-trips a stock package. It doesn't, because the command does not exist. Brute-forcing 36 verbs left exactly two standing, and the decompiled UPkgCommandlet::Main confirms it compares against precisely two string literals: list and expand. UCC's own printed usage text advertising import/export is a stale stub that does not describe the binary. Lesson recorded: never trust ucc help without running the command.

What that costs us. Reading assets out is solved — batchexport works, verified on a real texture. Writing them back has no verified path. Gameplay modding through PropertyOverrides is untouched and still needs zero binary writes; asset modding is now an open question rather than a solved one.

Next hypothesis — untestedThe UT-era way to build a texture package was never a commandlet. It is a .uc class carrying #exec TEXTURE IMPORT directives, compiled by ucc make, which emits the package. This game ships the EditPackages machinery that needs, and SWRC Fix 2.9 added a [UCC.Make] AutoLoad option specifically to smooth ucc make failures — all consistent with this being the live path. If it holds, asset import is solved without a binary writer. Stated as a hypothesis, not a finding.

Why the parser gets written from scratch

There is no maintained Python library for Unreal Engine 1 or 2 packages. Everything the search turns up is UE4/UE5 era — .pak and .uasset tooling that does not apply. That is a real gap, which is good news for whether this is worth building and bad news for how much can be borrowed.

  • Read-only first. Header, name table, import table, export table, object index. That alone powers res_find, prop_query, forge_verify and the packages.md5 decode.
  • Graded against UELib, which has explicit Republic Commando support and sits in the tools folder. Where our parse and UELib disagree, UELib is right until proven otherwise.
  • Version-aware from line one — five package versions in one install.
  • Karma files get xml.etree and about nine lines of code.

Non-goals for v1: native C++ compilation, multiplayer matchmaking, map geometry editing. The editor keeps that last job — the contribution here is making it launch and behave, not replacing it.

Why this page has a risk register at all

Projects like this rarely die of a dramatic bug. They die of a parser that silently corrupted something in week three, or a maintainer who lost a weekend to a checksum that turned out not to matter. So the failure modes got researched before the code got written.

Thirteen risks went on the board. One day of measurement killed one outright, defused one, and partly walked one back after the mitigation we were relying on failed its first test. The scoreboard below is the honest version, not the optimistic one.

A register that only ever moves in the reassuring direction is a register nobody is testing.
